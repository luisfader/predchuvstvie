# Предчувствие

Сайт всего романа Роберта Фадера «Предчувствие» — все сезоны и саундтрек.
https://luisfader.github.io/predchuvstvie/

- `index.html` — читалка: части, оглавления, главы, плеер
- `saga.json` — части романа и списки глав (собирается скриптом)
- `books/<часть>/` — главы в Markdown, `cover.jpg`, иллюстрации в `img/` (JPG)
  - `1` — «Предчувствие», `2` — «Предчувствие 2», `2-2`, `2-3`, `2-4`
- `audio/` — саундтрек: MP3 и `tracks.json`
- `tools/sync_from_litmir.py` — обновляет все части из репозитория litmir
- `tools/extras.json` — иллюстрации, которые есть только на этом сайте

## Обновление текста из litmir

```
python3 tools/sync_from_litmir.py ../litmir
```

## Саундтрек

`audio/tracks.json`: `part` — часть (`"2-2"`), `chapters` — главы, в которых трек
включается автоматически, `song: true` — песня, иначе инструментал.

Старые ссылки вида `#/05` ведут на главы «Предчувствия 2.2» (`#/2-2/05`).
